# OCR-TB CLI v4 — implementation plan

Approved specification: ../specs/2026-10-17-ocr-tb-v4-design.md and the v4 plan in chat.

- [x] Task 1: local assets, immutable samples, doctor and raw OCR baseline.
- [x] Task 2: bounded preprocessing, border detection, selection and metrics (test first).
- [x] Task 3: supervised child process, sequential batch, CLI, timeout and recovery.
- [x] Task 4: evaluation, controlled experiments A–D, offline tests and documentation.
- [x] Whole-project independent review and verification.

Constraints: Node 24 ESM, Sharp, Tesseract.js/core 7.0.0, no runtime network,
metadata-only IPC, one reused worker, no labels in recognition/selection,
no source image mutation, honest three-sample report.

Review focus: preprocessing bounds after padding; hanging child recovery and
initialization failure; confidence/tie semantics; missing or tampered assets;
metric denominators including operational errors.
